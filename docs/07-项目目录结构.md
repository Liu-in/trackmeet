# 项目目录结构

## 关键目录说明

| 目录 | 说明 |
| --- | --- |
| `backend/.../engine/` | **全部田径算法集中于此**，纯函数、无数据库依赖，便于单元测试与规则可配置 |
| `backend/.../modules/` | 按业务域分包，每包内 `controller / service / mapper / entity / dto / convert` 分层 |
| `backend/.../resources/templates/` | 报表模板：Excel（EasyExcel）、PDF（OpenPDF/HTML）、字体 |
| `frontend/src/components/ProTable` | 统一列表能力（分页/搜索/排序/列设置/导出），保证 NFR-13 |
| `frontend/src/views/printviews/` | 12 个 A4 打印视图，与打印中心解耦，可独立打开用于 `window.print()` |
| `frontend/src/views/screen/` | 大屏页面，独立布局、无鉴权壳、定时轮询 |
| `deploy/mysql/init/` | 首次启动自动建库建表并灌入初始化数据，实现「一键启动即有账号可用」 |
