# 需求规格说明书（SRS）

> 项目：田径运动会编排软件 TrackMeet ｜ 版本 v1.0 ｜ 阶段：设计基线

## 1. 项目概述

### 1.1 背景与目标
面向中小学、高校、企事业单位田径运动会的竞赛组织全流程，替代「Excel + 手工编排」的传统做法，实现：

1. **一次录入、全程复用**：报名数据贯穿编排、检录、成绩、积分、证书。
2. **规则可配置**：录取名次、晋级规则、名次分表、破纪录加分、接力双倍分、兼项间隔、道次顺序、风速限制、全能计分表全部可配置。
3. **自动编排 + 人工干预**：自动生成竞赛日程与分组分道，支持拖拽调整、锁定、局部重排。
4. **冲突可发现**：运动员兼项、场地冲突、裁判冲突、时间间隔不足四类冲突自动检测。
5. **输出规范**：秩序册、检录表、分道表、成绩公告、成绩册、积分表、奖牌榜、证书一键生成（PDF/Excel/Word/CSV）。
6. **局域网可用**：Docker Compose 一键部署，数据可备份恢复，无外网依赖。

### 1.2 系统范围
**包含**：系统管理、运动会管理、运动员与报名、项目管理与规则配置、编排管理、赛前管理、成绩管理、统计与积分、打印与导出、大屏与公告。

**不包含（本期）**：
- 电子计时/测距设备硬件对接（仅预留 `device_data` 导入接口与统一成绩写入 API）。
- 在线支付、短信通知（验证码为可选图形验证码）。
- 多语言国际化、移动端原生 App（前端做响应式适配，支持平板与手机浏览器）。

## 5. 关键算法需求（概要，阶段 5–8 实现）

| 算法 | 要点 |
| --- | --- |
| 径赛分组 | 按报名成绩降序排序 → 蛇形（S 型）分配到各组 → 同单位运动员尽量避开（冲突时以人数均衡优先）→ 人数差 ≤ 1 |
| 道次分配 | 按可配置道次顺序（默认 8 道 4,5,3,6,2,7,1,8；6 道 3,4,2,5,1,6）依次分配；成绩最好者占最优道次；种子/抽签可选 |
| 冲突检测 | 同一运动员时间重叠、场地时间重叠、裁判时间重叠、相邻项目时间差 < 兼项间隔 → 生成冲突记录 |
| 晋级 | 各组前 N 名直接晋级 + 其余按最好成绩排序递补至目标人数；同名次成绩并列时全部录取或按规则截断 |
| 积分 | 名次 → 名次分表取值（并列按均分/满额法）→ 破纪录加分 → 接力双倍 → 写入 `points` 明细 → 汇总 `team_score` |
| 全能 | 按 `allround_event` 固定顺序取单项成绩 → 查 `allround_score_table` 得分 → 累加总分 → 打分排名；缺项按规则处理 |
| 田赛 | 预赛取前 N（及格标准）进决赛；多次试跳取最好；平局按次优成绩 → 最远成功轮次 → 并列 |

## 6. 约束与依赖

1. 运行环境：Docker 20+ / Docker Compose v2；MySQL 8.0；Java 17；Node 18+（构建期）。
2. 单机（或单服务器）部署，不设计分布式与读写分离（预留接口）。
3. 全能计分表、纪录数据需业务方提供权威数据源或采用内置表并允许导入覆盖。
4. 电子计时设备对接不在本期，仅预留导入通道。
5. 浏览器需支持 ES2020 与 Canvas 打印。
