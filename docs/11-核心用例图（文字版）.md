# 核心用例图（文字版）

> 表达约定：
> `【参与者】` 人/系统；`(用例)` 业务用例；`<<include>>` 必然包含的子用例；`<<extend>>` 条件触发的扩展用例；`──▶` 参与关系；`══▶` 泛化（子用例继承父用例流程）。
> 系统边界用 `┌─── 系统名 ───┐` 表示。

## 3. 项目与规则域用例图

```
【编排员】─┬──▶(项目维护)──<<extend>>──(按组别×性别批量生成标准项目)
          ├──▶(轮次维护)──<<include>>──(轮次顺序与决赛标记)
          ├──▶(录取名次配置)
          ├──▶(晋级规则配置)──(每组前 N + 剩余最好成绩递补 + 目标人数)
          ├──▶(兼项间隔配置)
          ├──▶(道次顺序配置)──(8 道 4,5,3,6,2,7,1,8 / 6 道 3,4,2,5,1,6 / 自定义)

          ├──▶(田赛规则配置)──(试跳试掷次数、及格标准、升杆方案、平局规则)
          └──▶(全能项目配置)──<<include>>──(固定顺序与间隔) ──<<include>>──(单项计分表)

【系统】──────▶(规则解析)──(轮次级 > 项目级 > 届次级 > 系统默认，支持"恢复继承")
```

## 4. 编排域用例图（核心）

```
【编排员】─┬──▶(竞赛单元维护)──(日期/半天/起止时间/场地)
          │
          ├──▶(自动编排日程)──┬──<<include>>──(参赛人数与时长汇总)
          │                  ├──<<include>>──(场地与单元时间轴装箱)
          │                  ├──<<include>>──(保留锁定条目)
          │                  └──<<extend>>───(时间不足时输出缺口报告)
          │
          ├──▶(分组分道)──┬──<<include>>──(径赛分组)──┬─(按报名成绩排序)
          │              │                          ├─(蛇形 S 型排列)
          │              │                          ├─(同单位避开)
          │              │                          └─(人数均衡，差 ≤ 1)
          │              ├──<<include>>──(道次分配)──(按可配道次顺序，最优道次给最好成绩)
          │              └──<<include>>──(田赛顺序编排)──(随机/按成绩/按单位/按号码)
          │
          ├──▶(冲突检测)──┬─(运动员兼项冲突)
          │              ├─(场地冲突)
          │              ├─(裁判冲突)
          │              └─(时间间隔不足)──<<extend>>──(一键定位并高亮)
          │
          ├──▶(手动调整)──┬─(拖拽日程：跨单元/时段/场地)
          │              ├─(拖拽换组 / 道次交换)
          │              └─(田赛顺序调整)
          │
          ├──▶(锁定/解锁)──(锁定后重新生成保持不变)
          ├──▶(重新生成)──┬─(全量重排)
          │              └─(局部重排：按项目/按单元)
          ├──▶(编排快照与回滚)
          └──▶(生成秩序册)──┬─(总日程表)
                            ├─(分组表 / 分道表)
                            ├─(检录表)
                            └─(裁判安排表)
```

## 6. 成绩域用例图

```
【裁判】───┬──▶(成绩录入)──┬─(径赛：时间，手计时/电计时)
           │              ├─(田赛：远度/高度 + 每次试跳试掷)
           │              ├─(全能：单项成绩 → 查表得分 → 总分)

           │              └─(风速录入) ──<<extend>>──(超风速 > 上限自动标记)
           └──▶(提交审核)

【裁判长】─┬──▶(成绩审核)──┬─(批量通过)
           │              ├─(驳回并说明原因)
           │              └─(撤销审核，需填写原因) ──<<include>>──(成绩留痕写入)
           ├──▶(修改成绩) ──<<include>>──(前后值留痕 result_audit)
           └──▶(破纪录认定)──┬─(对标纪录层级)
                            ├─(风速合法性判定)
                            └─(写入纪录表 record)

【系统】───┬──▶(名次生成)──(按成绩/风速/犯规/平局规则)
           ├──▶(自动晋级)──┬─(每组前 N 名直接晋级)
           │              ├─(剩余人员按最好成绩递补至目标人数)
           │              ├─(剔除 DNS/DNF/DSQ/NM 与非法风速成绩)
           │              └──<<extend>>──(边界并列：全部录取或人工裁决)
           └──▶(成绩公告推送) ──▶ 大屏 / 网页 / 打印

【宣告员】─┬──▶(成绩公告发布/撤回)
           └──▶(成绩册生成) ──▶(PDF/Excel/Word)
```

## 9. 用例关系汇总（include / extend / 泛化）

| 关系 | 源用例 | 目标用例 | 说明 |
| --- | --- | --- | --- |
| include | 自动编排日程 | 参赛人数与时长汇总、时间轴装箱、保留锁定条目 | 编排必做的子步骤 |
| include | 自动编排日程 | 冲突检测 | 编排完成后必然执行 |
| include | 分组分道 | 径赛分组、道次分配、田赛顺序编排 | 三类分项能力 |
| include | 径赛分组 | 按报名成绩排序、蛇形排列、同单位避开、人数均衡 | 算法实施细则 |
| include | 道次分配 | 按可配道次顺序分配 | 规则可配置体现点 |
| include | 在线报名 | 报名限制校验 | 报名必做校验 |
| include | 报名限制校验 | 每人限报项数、每单位每项限报、兼项限制、重复检查 | 校验子项 |
| include | 成绩录入 | 径赛/田赛/全能录入、状态标记、风速录入 | 录入构成 |
| include | 成绩审核 | 成绩留痕写入 | 审核即留痕 |
| include | 自动晋级 | 每组前 N + 递补 + 剔除无效成绩 | 晋级算法 |
| include | 积分计算 | 名次分、破纪录加分、接力双倍 | 三类计分来源 |
| extend | 报名审核 | 退回并说明原因 | 条件触发 |
| extend | 成绩审核 | 撤销审核 | 条件触发 |
| extend | 成绩录入 | 超风速自动标记 | 条件触发（风速 > 上限） |
| extend | 自动编排日程 | 缺口报告 | 条件触发（时间/场地不足） |
| extend | 自动晋级 | 边界并列人工裁决 | 条件触发（递补边界并列） |
| extend | 运动员建档 | Excel 批量导入 → 错误报告下载 | 可选路径 |
| extend | 规则配置 | 规则模板导入导出 | 可选路径 |
| 泛化 | 径赛分组 ══▶ 分组分道；田赛顺序编排 ══▶ 分组分道 | 分项继承统一编排入口 |
| 泛化 | 获奖证书 ══▶ 证书生成；成绩证书 ══▶ 证书生成；参赛证书 ══▶ 证书生成 | 证书类型泛化 |
