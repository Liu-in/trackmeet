## 1. 类型规范

| 用途 | MySQL 类型 | 说明 |
| --- | --- | --- |
| 主键 / 外键 | `BIGINT UNSIGNED` | 自增主键 `AUTO_INCREMENT`；外键同类型 |
| 布尔 | `TINYINT(1)` | 0/1，字段名以 `is_` 开头 |
| 枚举/字典码 | `VARCHAR(32)` | 存英文码（如 `TRACK`、`APPROVED`），显示名从字典取 |
| 短文本 | `VARCHAR(50/64/100)` | 姓名 50、编码 64、名称 100 |
| 身份证号 | `VARCHAR(32)` | 兼容港澳台/护照号，不做类型强校验 |
| 长文本 | `TEXT` / `LONGTEXT` | 规程 HTML、模板 HTML |
| 时间点 | `DATETIME` | `create_time` 默认 `CURRENT_TIMESTAMP` |
| 日期 / 时刻 | `DATE` / `TIME` | 赛期、单元起止 |
| 成绩数值 | `DECIMAL(10,2)` | 秒、米、分；用于**排序比较** |
| 成绩原文 | `VARCHAR(16)` | 如 `11"23`、`1:02.45`，用于**显示** |
| 分值/金额 | `DECIMAL(10,2)` | 积分、加分、倍数 |
| 规则/快照 | `JSON` | 规则配置、前后值留痕、快照 |
| 序号 | `INT` / `SMALLINT` | 组号、道次、名次 |

## 2. 通用字段（除注明外，所有业务表均含）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT UNSIGNED PK AI | 主键 |
| `meet_id` | BIGINT UNSIGNED NOT NULL | 届次隔离字段（`sys_*` 表与全局字典表不含） |
| `create_by` | BIGINT UNSIGNED | 创建人 `sys_user.id` |
| `create_time` | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | BIGINT UNSIGNED | 修改人 |
| `update_time` | DATETIME ON UPDATE CURRENT_TIMESTAMP | 修改时间 |
| `deleted` | TINYINT(1) DEFAULT 0 | 逻辑删除（MyBatis-Plus） |
| `version` | INT DEFAULT 0 | 乐观锁（成绩、编排、报名等并发场景） |

> 各层字段清单中的「业务字段」表不再重复列出以上通用字段。

## 3. 命名与约束规范

| 规则 | 说明 |
| --- | --- |
| 表名 | 小写下划线；`sys_` 前缀为系统表；业务表无前缀 |
| 外键字段 | `<实体>_id`，与被引用表主键同名（如 `event_id`、`round_id`、`registration_id`） |
| 布尔字段 | `is_xxx`（`is_final`、`is_relay`、`is_locked`） |
| 时间字段 | `xxx_time`（DATETIME）/ `xxx_date`（DATE） |
| JSON 字段 | `xxx_json`，只存扩展/快照，不参与高频 WHERE |
| 唯一约束 | `uk_<字段组合>`，如 `uk(meet_id, id_card)` |
| 普通索引 | `idx_<字段组合>`，顺序：等值列在前、范围列在后 |
| 禁止 | 保留字表名（`group`/`rank`/`system`）、外键物理约束（应用层保证，便于备份恢复与批量导入） |

| 表.字段 | 内容示例 |

## 6. 并发与一致性约定

1. **乐观锁**：`result`、`schedule`、`heat`、`registration`、`event_rule_config` 使用 `version`；更新时校验版本，冲突返回 `409`。
2. **幂等**：成绩、报名写接口支持 `clientToken`；重复提交返回首次结果，不重复写业务表。
3. **逻辑删除**：`deleted=1` 保留数据；唯一约束需带 `deleted` 列或用「删除时改写唯一键」策略（如 `bib_no` 追加 `_d{id}`）。
4. **审计**：所有写操作写 `sys_operation_log`；成绩、规则、编排额外写业务留痕表。
