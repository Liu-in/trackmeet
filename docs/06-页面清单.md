# 页面清单

> 前端路由：`/login` 为独立布局，其余页面位于主布局 `Layout` 下（侧边菜单 + 顶栏 + 面包屑 + 多页签）。
> 打印页面位于 `/print/*` 独立无壳布局（A4 专用，支持 `window.print()` 与「另存为 PDF」）。
> 大屏页面位于 `/screen/*` 独立全屏布局。
> 权限编码格式：`模块:操作`，前端通过 `v-perm` 指令与路由守卫双重控制。

## 5. 交互与体验要点

1. **向导式自动编排**：范围 → 参数（是否保留锁定、分组方式）→ 结果预览 → 冲突确认 → 应用。
2. **拖拽**：日程拖拽（跨单元/时段/场地）与分组拖拽（跨组、道次交换）均需即时校验并给出冲突提示。
3. **锁定视觉**：锁定条目显示锁图标并置灰不可拖拽，明确提示「重新生成不会改变」。
4. **成绩录入键盘流**：支持 `Tab/Enter` 快速跳转、一键复制上一人成绩格式、批量填状态。
5. **冲突标红 + 定位**：点击冲突项自动滚动并高亮到对应日程/分组。
6. **多页签与状态保持**：编排、录入页面切走再回不丢草稿（Pinia + 本地缓存）。
7. **A4 打印样式**：`@page { size: A4; margin: 12mm }`，页眉页脚、页码、表格不跨页断裂（`break-inside: avoid`）。
8. **响应式**：管理页按 1366×768 以上设计；大屏按 1920×1080 与 3840×2160 适配。
