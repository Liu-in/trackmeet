# 后端项目目录结构（Spring Boot 3 + Java 17 + MyBatis-Plus）

> 根目录：`backend/` ｜ 包名：`com.trackmeet` ｜ 构建：Maven ｜ 部署：可执行 jar + Dockerfile
> 分层：`Controller → Service → Mapper → Entity`；算法全部集中在 `engine/`，纯函数、无数据库依赖。

## 2. 分层与命名约定

| 层 | 命名 | 职责 | 禁止 |
| --- | --- | --- | --- |
| Controller | `XxxController` | 参数校验（`@Valid`）、权限注解、调用 Service、返回 `R<T>` | 写业务逻辑、直接调 Mapper |
| Service | `XxxService` / `XxxServiceImpl` | 业务逻辑、事务边界（`@Transactional`）、数据权限二次校验 | 拼 SQL |
| Mapper | `XxxMapper` (+XML) | 单表 CRUD 由 MP 提供；复杂查询/统计写 XML | 业务判断 |
| Entity | `Xxx` | 与表一一对应，继承 `BaseEntity` | 直接返回给前端 |
| DTO/VO | `XxxDTO` / `XxxVO` | 入参 / 出参，MapStruct 转换 | 混用 |
| Engine | `XxxEngine` / `XxxResolver` | 纯算法，无数据库依赖，可独立单测 | 注入 Mapper |

## 4. 接口与配置约定

| 项 | 约定 |
| --- | --- |
| 统一返回 | 所有 Controller 返回 `R<T>`；分页返回 `R<PageResult<T>>` |
| 参数校验 | DTO 上 `@NotNull/@Size/@Pattern`，错误由全局异常处理器转 `400` |
| 事务 | 写操作 `@Transactional(rollbackFor = Exception.class)`；批量导入采用分批提交（每 500 条） |
| 幂等 | `@Idempotent(key = "#dto.clientToken")`，Redis/本地缓存记录首次结果 |
| 乐观锁 | 实体 `@Version`，更新影响行数为 0 时抛 `409` |
| 时间格式 | 入出参统一 `yyyy-MM-dd HH:mm:ss`；成绩时间用 `TimeParser` 解析为秒 |
| 日志 | `@OpLog(module="编排", action="自动编排")` 自动记录 |
| 环境配置 | `dev` 本地；`prod` 容器；敏感项（DB 密码、JWT 密钥）走环境变量 |
