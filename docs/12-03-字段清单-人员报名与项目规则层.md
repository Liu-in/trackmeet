# 人员报名层与项目规则层字段清单

> 本文覆盖 **15 张表**：人员与报名层 5 张（`athlete`、`registration`、`relay_member`、`registration_limit`、`athlete_event_count`）+ 项目与规则层 10 张（`event`、`event_round`、`event_round_rule`、`event_rule_config`、`score_rule`、`score_rule_item`、`bonus_rule`、`allround_event`、`allround_score_table`、`event_schedule_rule`）。
> 通用字段见 [字段清单总览](12-00-字段清单总览.md)：`id`、`meet_id`、`create_by`、`create_time`、`update_by`、`update_time`、`deleted`、`version`，下表**只列业务字段**，不重复列出。
> 类型严格遵循总览第 1 节：主键/外键 `BIGINT UNSIGNED`、布尔 `TINYINT(1)`、枚举码 `VARCHAR(32)`、短文本 `VARCHAR(50/64/100)`、号码/身份证 `VARCHAR(32)`、成绩数值 `DECIMAL(10,2)`、成绩原文 `VARCHAR(16)`、规则/快照 `JSON`、序号 `INT`/`SMALLINT`。
> 规则可配置要求：本文承载需求文档第 3 节 R-01 ~ R-22 的全部配置项，映射对照见文末。

---

## 一、人员与报名层（5 张）

### athlete 运动员表
> 参赛的「人」：届次内的运动员档案，关联组别与参赛单位。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `athlete_name` | VARCHAR(50) | 运动员姓名 |
| `gender` | VARCHAR(32) | 性别码 `MALE`/`FEMALE` |
| `birth_date` | DATE | 出生日期，用于组别年龄校验 |
| `id_card` | VARCHAR(32) | 身份证/护照号，届次内唯一 |
| `group_id` | BIGINT UNSIGNED | 所属组别 `meet_group.id` |
| `unit_id` | BIGINT UNSIGNED | 所属参赛单位 `unit.id` |
| `bib_no` | VARCHAR(32) | 号码布编号，届次内唯一 |
| `class_name` | VARCHAR(64) | 班级/年级名称 |
| `phone` | VARCHAR(32) | 联系电话 |
| `guardian` | VARCHAR(50) | 监护人姓名（青少年赛事） |
| `guardian_phone` | VARCHAR(32) | 监护人联系电话 |
| `qualification_status` | VARCHAR(32) | 资格状态 `PENDING`/`QUALIFIED`/`DISQUALIFIED` |
| `qualify_remark` | VARCHAR(100) | 资格审核说明 |
| `is_relay_only` | TINYINT(1) | 是否仅参加接力项目 |
| `photo_file_id` | BIGINT UNSIGNED | 照片附件 `sys_file.id` |
| `entry_source` | VARCHAR(32) | 数据来源 `MANUAL`/`IMPORT` |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(meet_id, id_card)`、`UK(meet_id, bib_no)`、`IDX(meet_id, unit_id, group_id)`、`IDX(qualification_status)`；逻辑删除时 `bib_no` 改写为 `原值_d{id}` 以保留唯一性。

### registration 报名表
> 运动员 × 项目的报名关系：个人项目 1 行 1 人，接力项目 1 行 N 人（队员存 `relay_member`）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_id` | BIGINT UNSIGNED | 报名项目 `event.id` |
| `athlete_id` | BIGINT UNSIGNED | 个人项目运动员 ID，接力为空 |
| `unit_id` | BIGINT UNSIGNED | 报名单位 ID |
| `group_id` | BIGINT UNSIGNED | 报名组别 ID |
| `round_scope` | VARCHAR(32) | 报名范围 `WHOLE` 全程/`FINAL_ONLY` 只报决赛 |
| `is_relay` | TINYINT(1) | 是否接力项目报名 |
| `relay_name` | VARCHAR(100) | 接力队名（如「XX 单位 A 队」） |
| `relay_team_seq` | SMALLINT | 同单位同项目接力队序号 |
| `seed_result` | VARCHAR(16) | 种子成绩原文，如 `11"23`、`1:02.45` |
| `seed_value` | DECIMAL(10,2) | 种子成绩可比较数值（秒/米） |
| `seed_result_unit` | VARCHAR(32) | 种子成绩单位 `s`/`m`/`cm`/`pt` |
| `seed_source` | VARCHAR(32) | 种子来源 `PB`/`SB`/`LAST_MEET`/`CUSTOM` |
| `seed_source_meet_id` | BIGINT UNSIGNED | 上届成绩来源届次 `meet.id` |
| `seed_time` | DATETIME | 种子成绩产生时间 |
| `status` | VARCHAR(32) | `PENDING`/`APPROVED`/`REJECTED`/`CANCELLED` |
| `reject_reason` | VARCHAR(100) | 退回原因 |
| `check_result_json` | JSON | 限报校验快照：超项/超人数/重复/组别不符 |
| `submit_time` | DATETIME | 报名提交时间 |
| `audit_by` | BIGINT UNSIGNED | 审核人 `sys_user.id` |
| `audit_time` | DATETIME | 审核时间 |
| `client_token` | VARCHAR(64) | 幂等令牌，防重复提交 |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：个人项目 `UK(meet_id, event_id, athlete_id)`；接力项目 `UK(meet_id, event_id, unit_id, relay_team_seq)`；`IDX(meet_id, unit_id, status)`、`IDX(status)`、`IDX(event_id, status)`。

### relay_member 接力队员表
> 接力报名下的队员与棒次明细。

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| `athlete_id` | BIGINT UNSIGNED | 队员运动员 ID |
| `athlete_name` | VARCHAR(50) | 队员姓名冗余，便于打印 |
| `leg_no` | SMALLINT | 棒次号，1 起 |
| `unit_id` | BIGINT UNSIGNED | 队员所属单位 ID |

| `status` | VARCHAR(32) | 状态 `NORMAL`/`CHANGED`/`CANCELLED` |
| `change_reason` | VARCHAR(100) | 换人/调整原因 |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(registration_id, leg_no)`、`IDX(athlete_id)`、`IDX(registration_id, is_reserve)`。

### registration_limit 报名限制计数表
> 按「单位 × 项目」维护限报快照与实时计数，供报名校验与列表展示。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `unit_id` | BIGINT UNSIGNED | 参赛单位 ID |
| `event_id` | BIGINT UNSIGNED | 项目 ID |
| `group_id` | BIGINT UNSIGNED | 组别 ID |
| `registered_count` | INT | 本单位该项目已报人数 |
| `max_count` | INT | 每单位每项限报人数（生效值） |
| `relay_registered_count` | INT | 已报接力队数 |
| `relay_max_count` | INT | 接力限报队数 |
| `remain_count` | INT | 剩余可报人数 |
| `is_full` | TINYINT(1) | 是否已达上限 |
| `over_limit` | TINYINT(1) | 是否超限（含已批准超额） |
| `athlete_event_count_json` | JSON | 单位内各运动员项数明细快照 |
| `limit_source` | VARCHAR(32) | 限值来源 `MEET`/`EVENT`/`DICT` |
| `limit_check_time` | DATETIME | 最近一次校验时间 |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(meet_id, unit_id, event_id)`、`IDX(meet_id, event_id, is_full)`、`IDX(unit_id, group_id)`。

### athlete_event_count 每人项数计数表
> 按运动员维护已报项数与超项标记，承载「每人限报项数」校验。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `athlete_id` | BIGINT UNSIGNED | 运动员 ID |
| `unit_id` | BIGINT UNSIGNED | 所属单位 ID |
| `group_id` | BIGINT UNSIGNED | 所属组别 ID |
| `event_count` | INT | 已报项数合计 |
| `individual_event_count` | INT | 个人项目项数 |
| `relay_event_count` | INT | 接力项目项数 |
| `allround_event_count` | INT | 全能项目项数 |
| `max_events` | INT | 每人限报项数上限（生效值） |
| `remain_count` | INT | 剩余可报项数 |
| `is_relay_counted` | TINYINT(1) | 接力是否计入限报项数 |
| `over_limit` | TINYINT(1) | 是否超项 |
| `event_ids_json` | JSON | 已报项目 ID 明细快照 |
| `count_source` | VARCHAR(32) | 上限来源 `MEET`/`EVENT`/`DICT` |
| `last_register_time` | DATETIME | 最近一次报名时间 |
| `check_time` | DATETIME | 计数刷新时间 |

**索引与约束**：`UK(athlete_id)`、`IDX(meet_id, over_limit)`、`IDX(unit_id, group_id)`。

## 二、项目与规则层（10 张）

### event 项目表
> 项目主数据：类型、组别、性别、赛制、接力人数、限报与计分属性。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_name` | VARCHAR(100) | 项目名称 |
| `event_code` | VARCHAR(64) | 项目编码，届次内唯一 |
| `event_type` | VARCHAR(32) | `TRACK`/`FIELD`/`ALLROUND`/`RELAY` |
| `sub_type` | VARCHAR(32) | `SPRINT`/`MIDDLE`/`LONG`/`HURDLE`/`STEEPLE`/`WALK`/`JUMP`/`THROW`/`RELAY` |
| `group_id` | BIGINT UNSIGNED | 所属组别 `meet_group.id` |
| `gender` | VARCHAR(32) | `MALE`/`FEMALE`/`MIXED` |
| `round_count` | SMALLINT | 轮次数量 |
| `is_relay` | TINYINT(1) | 是否接力项目 |
| `relay_min` | SMALLINT | 接力最少人数（默认 4） |
| `relay_max` | SMALLINT | 接力最多人数（默认 4） |
| `max_per_unit` | INT | 每单位每项限报人数（默认 3） |
| `is_relay_double` | TINYINT(1) | 接力得分是否双倍（关联 `bonus_rule.factor`） |
| `wind_applicable` | TINYINT(1) | 是否记录并判定风速 |
| `is_team_score` | TINYINT(1) | 是否计入团体总分 |
| `duration_min` | INT | 项目预计时长（分钟） |
| `score_rule_id` | BIGINT UNSIGNED | 采用名次分方案 `score_rule.id` |
| `unit_of_measure` | VARCHAR(32) | 计量单位 `s`/`m`/`cm`/`pt` |
| `result_precision` | SMALLINT | 成绩小数位（覆盖 `sys_config` 精度） |
| `sort_no` | INT | 显示排序号 |
| `status` | VARCHAR(32) | `ENABLED`/`DISABLED` |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(meet_id, event_code)`、`IDX(meet_id, group_id, event_type)`、`IDX(meet_id, is_relay)`、`IDX(status)`。

### event_round 轮次表
> 项目内的比赛轮次定义与编排计划值。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_id` | BIGINT UNSIGNED | 所属项目 ID |
| `round_code` | VARCHAR(32) | `QUALIFY`/`PRE`/`R1`/`R2`/`SEMI`/`FINAL` |
| `round_name` | VARCHAR(100) | 轮次名称（如「预赛」「决赛」） |
| `round_no` | SMALLINT | 轮次顺序号，1 起 |
| `is_final` | TINYINT(1) | 是否决赛轮 |
| `plan_heat_count` | SMALLINT | 计划分组数 |
| `plan_heat_size` | SMALLINT | 每组计划人数 |
| `plan_advance_count` | INT | 计划晋级总人数 |
| `plan_advance_group_top` | SMALLINT | 计划每组晋级人数 |
| `plan_best_loser_count` | SMALLINT | 计划递补人数（剩余最好成绩） |
| `entry_count` | INT | 本轮实际参与人数（快照） |
| `round_date` | DATE | 计划比赛日期 |
| `status` | VARCHAR(32) | `PLANNED`/`READY`/`RUNNING`/`FINISHED` |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(event_id, round_code)`、`IDX(event_id, round_no)`、`IDX(meet_id, round_date)`；`plan_*` 为编排计划值，规则值以 `event_round_rule` 为准。

### event_round_rule 轮次级规则表
> 三层继承中的最内层：本轮录取名次与晋级/递补规则。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `round_id` | BIGINT UNSIGNED | 轮次 `event_round.id`，一对一 |
| `event_id` | BIGINT UNSIGNED | 所属项目 ID，便于按项目查询 |
| `admit_rank` | SMALLINT | 本轮录取名次（取前 N 名） |
| `group_top_n` | SMALLINT | 每组直接晋级前 N 名（默认 2） |
| `best_loser_count` | SMALLINT | 剩余最好成绩递补人数（默认 8） |
| `target_count` | INT | 目标晋级总人数 |
| `advance_json` | JSON | 晋级规则扩展，如 `{"groupTop":2,"bestLoser":8,"target":16,"excludeIllegalWind":true}` |
| `tie_break_json` | JSON | 本轮平局判定规则（次优成绩→最远成功轮次→并列） |
| `source_round_id` | BIGINT UNSIGNED | 晋级来源轮次 ID（上一轮） |
| `is_inherit` | TINYINT(1) | 未配置项是否继承项目级规则 |
| `exclude_illegal_wind` | TINYINT(1) | 超风速成绩是否排除出递补 |
| `manual_advance_count` | SMALLINT | 人工指定晋级人数（覆盖自动计算） |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(round_id)`、`IDX(event_id)`、`IDX(source_round_id)`；`version` 乐观锁保护规则并发修改。

### event_rule_config 项目级规则表
> 项目级规则中枢：录取、分组、道次、风速、试跳、升杆、平局、时长等全部可配置项。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_id` | BIGINT UNSIGNED | 项目 `event.id`，一对一 |
| `admit_rank` | SMALLINT | 录取名次（取前 N 名，默认 8） |
| `draw_mode` | VARCHAR(32) | 分组方式 `SERPENT` 蛇形/`RANDOM`/`SEED` 成绩段/`UNIT` |
| `draw_avoid_same_unit` | TINYINT(1) | 分组时同单位是否避开 |
| `draw_group_size` | SMALLINT | 分组计划每组人数 |
| `lane_count` | SMALLINT | 本项目使用道数（8 道/6 道） |
| `lane_order_json` | JSON | 道次顺序，8 道 `[4,5,3,6,2,7,1,8]`；6 道 `[3,4,2,5,1,6]` |
| `lane_assign_mode` | VARCHAR(32) | 道次分配方式 `SEED`/`DRAW`/`SERPENT`/`ORDER` |
| `conflict_interval_min` | SMALLINT | 兼项最小间隔（分钟，默认 30） |
| `wind_json` | JSON | 风速规则，如 `{"applicable":true,"maxLegal":2.0}` |
| `attempt_count` | SMALLINT | 田赛预赛试跳/试掷次数（默认 3） |
| `final_attempt_count` | SMALLINT | 田赛决赛试跳/试掷次数（默认 3） |
| `qualify_standard` | VARCHAR(100) | 及格赛标准原文 |
| `qualify_standard_value` | DECIMAL(10,2) | 及格标准可比较数值 |
| `qualify_standard_unit` | VARCHAR(32) | 及格标准单位 `s`/`m`/`cm` |
| `height_plan_json` | JSON | 升杆方案（起跳高度、每轮升幅、免跳） |
| `tie_break_json` | JSON | 平局规则（次优成绩→最远成功轮次→并列） |
| `duration_min` | INT | 项目预计时长（分钟） |
| `is_inherit_meet` | TINYINT(1) | 未配置项是否继承届次默认值 |
| `extra_json` | JSON | 其他扩展规则（抽签种子数、重赛规则等） |

**索引与约束**：`UK(event_id)`、`IDX(meet_id, draw_mode)`；`version` 乐观锁；空值语义为「继承上一层」，实现 `event_round_rule` > `event_rule_config` > `meet.config_json` > 字典默认。

### score_rule 名次分方案表
> 名次分方案主表：并列计分方式、适用范围与默认标记。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rule_name` | VARCHAR(100) | 方案名称（如「单项前八名 9-7-6-5」） |
| `rule_code` | VARCHAR(64) | 方案编码，届次内唯一 |
| `tie_policy` | VARCHAR(32) | 并列计分 `AVERAGE` 均分/`FULL` 满额/`ORDER` 顺延 |
| `score_target` | VARCHAR(32) | 计分对象 `EVENT` 单项/`TEAM` 团体 |
| `rank_count` | SMALLINT | 计名次数量（明细行数） |
| `point_base` | DECIMAL(10,2) | 计分基准分（用于系数换算） |
| `is_default` | TINYINT(1) | 是否届次默认方案 |
| `apply_event_type` | VARCHAR(32) | 适用项目类型 `TRACK`/`FIELD`/`ALLROUND`/`RELAY`/`ALL` |
| `apply_gender` | VARCHAR(32) | 适用性别 `MALE`/`FEMALE`/`MIXED`/`ALL` |
| `group_id` | BIGINT UNSIGNED | 适用组别 ID，空为全部组别 |
| `effective_round_code` | VARCHAR(32) | 生效轮次码，空默认决赛 |
| `is_team_score` | TINYINT(1) | 是否计入团体总分 |
| `status` | VARCHAR(32) | `ENABLED`/`DISABLED` |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(meet_id, rule_code)`、`IDX(meet_id, is_default)`、`IDX(meet_id, apply_event_type, apply_gender)`。

### score_rule_item 名次分明细表
> 名次（或名次区间）到分值的映射明细，支持一表多方案。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rule_id` | BIGINT UNSIGNED | 所属方案 `score_rule.id` |
| `rank_no` | SMALLINT | 名次序号（区间行填区间起点） |
| `rank_from` | SMALLINT | 名次区间起（含） |
| `rank_to` | SMALLINT | 名次区间止（含） |
| `rank_label` | VARCHAR(50) | 名次显示名（如「第一名」） |
| `point_value` | DECIMAL(10,2) | 该名次/区间对应分值 |
| `bonus_point` | DECIMAL(10,2) | 该名次附加分 |
| `tie_policy` | VARCHAR(32) | 该名次并列处理，空继承主表 |
| `is_team_score` | TINYINT(1) | 该名次分是否计入团体总分 |
| `sort_no` | INT | 显示排序号 |
| `remark` | VARCHAR(100) | 备注 |

**索引与约束**：`UK(rule_id, rank_no)`、`IDX(rule_id, rank_from, rank_to)`；默认方案明细内置 `9,7,6,5,4,3,2,1`。

### bonus_rule 加分规则表
> 破纪录加分、接力双倍、破平局加分的可配置规则。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rule_name` | VARCHAR(100) | 加分规则名称 |
| `rule_code` | VARCHAR(64) | 规则编码，届次内唯一 |
| `bonus_type` | VARCHAR(32) | `RECORD` 破纪录/`RELAY` 接力双倍/`BREAK_TIE` 破平局 |
| `record_type` | VARCHAR(32) | 纪录层级 `WORLD`/`ASIA`/`NATION`/`PROVINCE`/`CITY`/`MEET`/`GROUP` |
| `bonus_point` | DECIMAL(10,2) | 破纪录加分值（默认赛会纪录 +9） |
| `is_stackable` | TINYINT(1) | 多层级纪录加分是否叠加 |
| `factor` | DECIMAL(10,2) | 倍数（接力双倍为 2.00） |
| `event_id` | BIGINT UNSIGNED | 适用项目 ID，空为全部项目 |
| `group_id` | BIGINT UNSIGNED | 适用组别 ID，空为全部组别 |

## 本层设计要点

1. **人—报名—队员三级关系**：`athlete` 是参赛主体，`registration` 是「人 × 项目」关系；个人项目 `athlete_id` 非空，接力项目 `is_relay=1` 且队员落在 `relay_member`，两类共用一张报名表，便于统一审核与限报校验。
2. **限报双计数**：`registration_limit` 管「单位 × 项目」人数上限（R-10），`athlete_event_count` 管「每人项数」上限（R-11）；两者都保存生效值与来源，规则改动后可回溯。
3. **种子成绩双列制**：所有成绩类字段统一 `seed_result VARCHAR(16)`（原文，供显示/打印）+ `seed_value DECIMAL(10,2)`（数值，供排序/分组/道次算法），避免字符串比较导致排序错误。
4. **校验快照可追溯**：`registration.check_result_json` 固化提交时刻的限报校验结果，即使后续规则调整也不影响历史判定的复现。
5. **规则三层继承**：`event_round_rule`（轮次）> `event_rule_config`（项目）> `meet.config_json`（届次）> 字典默认；`event_rule_config.is_inherit_meet` 与 `event_round_rule.is_inherit` 用于显式声明「继承」，任一层的空值即向下继承，无需硬编码。
6. **结构化列 + JSON 双轨**：高频参与计算/查询的规则用独立列（`admit_rank`、`draw_mode`、`attempt_count`、`conflict_interval_min`），结构松散的规则用 JSON（道次顺序、风速、升杆、平局、晋级），JSON 不参与高频 WHERE。
7. **道次顺序内置**：`lane_order_json` 默认 8 道 `[4,5,3,6,2,7,1,8]`、6 道 `[3,4,2,5,1,6]`，与 `venue.lane_count` 联动，届次与项目均可覆盖。
8. **计分完整闭环**：`score_rule`（方案，含 `tie_policy` 并列处理）→ `score_rule_item`（名次→分值）→ `bonus_rule`（破纪录/接力双倍/破平局）→ `event.score_rule_id`（项目绑定方案），使单项分与团体分计算零硬编码。
9. **全能独立建模**：`allround_event` 定义顺序、间隔与所属日，`allround_score_table` 定义成绩区间→得分并区分手/电计时，支持内置表与导入表共存。
10. **时长与顺序来源统一**：`event.duration_min` 为项目个性值，`event_schedule_rule` 为类型级默认值，编排取「项目值 > 类型默认 > 参数默认」，实现 R-19 可配置。
11. **并发与留痕**：`registration`、`event_rule_config` 使用 `version` 乐观锁；`registration` 支持 `client_token` 幂等；规则修改经通用审计字段与 `sys_operation_log` 留痕。
12. **逻辑删除下的唯一性**：`athlete.bib_no`、`athlete.id_card`、`registration` 唯一键在删除时采用「改写唯一键」策略（如 `bib_no` 追加 `_d{id}`），保证历史数据可保留且新数据可录入。
