# 成绩层与统计输出层字段清单

> 本文件列出**成绩层（6 张）**与**统计输出层（7 张）**的业务字段，共 13 张表。
> 通用字段见 [字段清单总览](12-00-字段清单总览.md)：`id, meet_id, create_by, create_time, update_by, update_time, deleted, version` 不在下文重复列出。
> 类型规范、命名与约束规范一律遵循总览第 1–3 节；本层枚举取值汇总见文末「三、本层枚举取值」一节。

---

## 一、成绩层（6 张）

### result 成绩表
> 一名运动员在一个日程条目（项目 × 轮次）上的最终成绩记录，是名次、积分、晋级、纪录与证书的唯一数据源。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `schedule_id` | BIGINT UNSIGNED | 日程条目 `schedule.id` |
| `heat_id` | BIGINT UNSIGNED | 所在分组 `heat.id` |
| `heat_member_id` | BIGINT UNSIGNED | 组内人员 `heat_member.id` |
| `event_id` | BIGINT UNSIGNED | 项目 `event.id` |
| `round_id` | BIGINT UNSIGNED | 轮次 `event_round.id` |
| `registration_id` | BIGINT UNSIGNED | 报名记录 `registration.id` |
| `athlete_id` | BIGINT UNSIGNED | 运动员 `athlete.id`（接力为队首人） |
| `unit_id` | BIGINT UNSIGNED | 参赛单位 `unit.id` |
| `group_id` | BIGINT UNSIGNED | 组别 `meet_group.id` |
| `lane_no` | SMALLINT | 道次号，田赛与长跑可为空 |
| `result_raw` | VARCHAR(16) | 成绩原文，如 `11"23`、`1:02.45` |
| `result_value` | DECIMAL(10,2) | 成绩数值（秒/米/分），用于排序比较 |
| `result_unit` | VARCHAR(8) | 成绩单位：`s` / `m` / `cm` / `pt` |
| `result_score` | DECIMAL(10,2) | 全能单项得分，非全能项为空 |
| `final_height` | DECIMAL(10,2) | 田赛高度项最终过杆高度（米） |
| `rank_no` | SMALLINT | 名次序号，并列时取相同值 |
| `rank_display` | VARCHAR(16) | 名次显示文本，如 `1`、`2`（并列） |
| `status` | VARCHAR(32) | 成绩状态 7 值，见「三、本层枚举取值」 |
| `foul_type` | VARCHAR(32) | 犯规类型码，取自犯规类型字典 |
| `foul_reason` | VARCHAR(200) | 判罚依据说明，DSQ 时必填 |
| `wind_speed` | DECIMAL(5,2) | 风速（m/s），顺风为正、逆风为负 |
| `is_wind_legal` | TINYINT(1) | 风速是否合法（1 合法 / 0 超风速） |
| `is_record_candidate` | TINYINT(1) | 是否破纪录候选 |
| `is_record_confirmed` | TINYINT(1) | 纪录是否已认定 |
| `record_id` | BIGINT UNSIGNED | 对标纪录 `record.id` |
| `record_type` | VARCHAR(32) | 认定纪录层级 7 值，见「三、本层枚举取值」 |
| `is_pb` | TINYINT(1) | 是否个人最好成绩 |
| `is_sb` | TINYINT(1) | 是否个人赛季最好成绩 |
| `is_manual` | TINYINT(1) | 是否手工录入（0 为设备导入） |
| `allround_group_id` | BIGINT UNSIGNED | 全能归并标识，同一全能用同值 |
| `audit_status` | VARCHAR(32) | 审核状态 4 值，见「三、本层枚举取值」 |
| `audit_by` | BIGINT UNSIGNED | 审核人 `sys_user.id` |
| `audit_time` | DATETIME | 审核时间 |
| `reject_reason` | VARCHAR(200) | 驳回原因，`REJECTED` 时必填 |
| `is_locked` | TINYINT(1) | 成绩锁定，锁定后须撤销审核才能改 |
| `client_token` | VARCHAR(64) | 幂等令牌，重复提交返回首次结果 |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`UK(schedule_id, registration_id)`、`UK(allround_group_id, event_id)`（同一全能内同类单项唯一）、`IDX(meet_id, event_id, round_id, audit_status)`、`IDX(athlete_id, event_id)`、`IDX(meet_id, unit_id, group_id)`、`IDX(client_token)`

### result_attempt 田赛试跳试掷表
> 田赛项目每一次试跳/试掷的明细，用于取名次前的平局比较与成绩复核。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `result_id` | BIGINT UNSIGNED | 所属成绩 `result.id` |
| `registration_id` | BIGINT UNSIGNED | 报名记录 `registration.id` |
| `attempt_no` | SMALLINT | 试跳/试掷总序号，从 1 递增 |
| `attempt_round` | SMALLINT | 轮次序号（第几轮次试跳） |
| `attempt_raw` | VARCHAR(16) | 单次成绩原文，如 `5.68` |
| `attempt_value` | DECIMAL(10,2) | 单次成绩数值（米/厘米） |
| `attempt_unit` | VARCHAR(8) | 单次成绩单位：`m` / `cm` |
| `height_value` | DECIMAL(10,2) | 本次横杆高度（高度项，米） |
| `is_success` | TINYINT(1) | 本次是否成功 |
| `is_pass` | TINYINT(1) | 是否免跳（PASS，不消耗试跳次数） |
| `is_foul` | TINYINT(1) | 是否犯规 |
| `foul_type` | VARCHAR(32) | 犯规类型码，取自犯规类型字典 |
| `is_best` | TINYINT(1) | 是否为该运动员最好一次 |
| `judge_id` | BIGINT UNSIGNED | 记录裁判 `referee.id` |
| `device_no` | VARCHAR(32) | 测距/计时设备编号 |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`UK(result_id, attempt_no)`、`IDX(registration_id, attempt_round)`

### wind_reading 风速读数表
> 风速仪读数留档，作为超风速标记与纪录认定的原始依据，一成绩一条。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `result_id` | BIGINT UNSIGNED | 关联成绩 `result.id` |
| `schedule_id` | BIGINT UNSIGNED | 日程条目 `schedule.id` |
| `heat_id` | BIGINT UNSIGNED | 分组 `heat.id` |
| `event_id` | BIGINT UNSIGNED | 项目 `event.id` |
| `wind_speed` | DECIMAL(5,2) | 风速读数（m/s） |
| `wind_direction` | VARCHAR(16) | 风向：`HEAD` / `TAIL` / `CROSS` |
| `is_wind_legal` | TINYINT(1) | 是否在合法上限内 |
| `legal_limit` | DECIMAL(5,2) | 本次判定采用的合法上限值 |
| `wind_device_no` | VARCHAR(32) | 风速仪设备编号 |
| `read_time` | DATETIME | 读数时间 |
| `recorder_id` | BIGINT UNSIGNED | 记录人 `sys_user.id` |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`UK(result_id)`、`IDX(schedule_id, heat_id)`

### result_audit 成绩留痕表
> 成绩提交、审核、驳回、修改、撤销的完整留痕链，保证「谁/何时/改了什么」可追溯。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `result_id` | BIGINT UNSIGNED | 关联成绩 `result.id` |
| `event_id` | BIGINT UNSIGNED | 项目 `event.id` |
| `round_id` | BIGINT UNSIGNED | 轮次 `event_round.id` |
| `registration_id` | BIGINT UNSIGNED | 报名记录 `registration.id` |
| `action` | VARCHAR(32) | 留痕动作 5 值，见「三、本层枚举取值」 |
| `before_json` | JSON | 变更前快照（含各次试跳） |
| `after_json` | JSON | 变更后快照（含各次试跳） |
| `reason` | VARCHAR(500) | 修改或驳回原因 |
| `operator_id` | BIGINT UNSIGNED | 操作人 `sys_user.id` |
| `operator_name` | VARCHAR(50) | 操作人姓名快照 |
| `operate_time` | DATETIME | 操作时间 |
| `ip` | VARCHAR(64) | 操作来源 IP |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`IDX(result_id, operate_time)`、`IDX(meet_id, action, operate_time)`

### advance_result 晋级名单表
> 记录「从哪一轮、以什么方式晋级到哪一轮」的名单，是自动晋级与人工递补的统一结果。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_id` | BIGINT UNSIGNED | 项目 `event.id` |
| `from_round_id` | BIGINT UNSIGNED | 来源轮次 `event_round.id` |
| `to_round_id` | BIGINT UNSIGNED | 目标轮次 `event_round.id` |
| `registration_id` | BIGINT UNSIGNED | 报名记录 `registration.id` |
| `athlete_id` | BIGINT UNSIGNED | 运动员 `athlete.id` |
| `unit_id` | BIGINT UNSIGNED | 参赛单位 `unit.id` |
| `group_id` | BIGINT UNSIGNED | 组别 `meet_group.id` |
| `source_heat_no` | SMALLINT | 来源组号 |
| `source_rank` | SMALLINT | 来源组内名次 |
| `source_result_value` | DECIMAL(10,2) | 来源轮次成绩数值（用于递补排序） |
| `source_result_raw` | VARCHAR(16) | 来源轮次成绩原文 |
| `advance_type` | VARCHAR(32) | 晋级方式 3 值，见「三、本层枚举取值」 |
| `advance_order` | SMALLINT | 晋级后在新轮次中的顺序号 |
| `is_confirmed` | TINYINT(1) | 名单是否已确认生效 |
| `confirm_by` | BIGINT UNSIGNED | 确认人 `sys_user.id` |
| `confirm_time` | DATETIME | 确认时间 |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`UK(event_id, to_round_id, registration_id)`、`IDX(from_round_id, advance_type)`

### result_import_log 设备成绩导入记录表
> 电子计时/测距设备导出文件的导入批次记录，便于结果核对与失败回查。

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| `schedule_id` | BIGINT UNSIGNED | 目标日程条目 `schedule.id` |

| `round_id` | BIGINT UNSIGNED | 轮次 `event_round.id` |

| `total_count` | INT | 文件总行数 |
| `success_count` | INT | 成功写入条数 |
| `fail_count` | INT | 失败条数 |
| `error_file_id` | BIGINT UNSIGNED | 错误报告文件 `sys_file.id` |
| `status` | VARCHAR(32) | 导入状态 5 值，见「三、本层枚举取值」 |
| `message` | VARCHAR(500) | 结果说明或错误摘要 |
| `operator_id` | BIGINT UNSIGNED | 导入操作人 `sys_user.id` |
| `finish_time` | DATETIME | 导入完成时间 |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`IDX(meet_id, status)`、`IDX(schedule_id, create_time)`

## 二、统计与输出层（7 张）

### points 积分明细表
> 一条「成绩 → 得分」的计算结果，记录名次分、破纪录加分与接力倍数的合成过程。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_id` | BIGINT UNSIGNED | 项目 `event.id` |
| `round_id` | BIGINT UNSIGNED | 轮次 `event_round.id` |
| `result_id` | BIGINT UNSIGNED | 来源成绩 `result.id` |
| `registration_id` | BIGINT UNSIGNED | 报名记录 `registration.id` |
| `athlete_id` | BIGINT UNSIGNED | 运动员 `athlete.id` |
| `unit_id` | BIGINT UNSIGNED | 计分单位 `unit.id` |
| `group_id` | BIGINT UNSIGNED | 组别 `meet_group.id` |
| `gender` | VARCHAR(16) | 性别：`MALE` / `FEMALE` / `MIXED` |
| `rank_no` | SMALLINT | 计分名次 |
| `rank_point` | DECIMAL(10,2) | 名次分，查 `score_rule_item` 得 |
| `bonus_point` | DECIMAL(10,2) | 破纪录加分合计 |
| `relay_factor` | DECIMAL(10,2) | 接力倍数，非接力为 1 |
| `total_point` | DECIMAL(10,2) | 合计分 = (名次分 + 加分) × 倍数 |
| `score_rule_id` | BIGINT UNSIGNED | 名次分方案 `score_rule.id` |
| `score_rule_code` | VARCHAR(64) | 方案编码快照 |
| `bonus_rule_ids` | VARCHAR(200) | 命中的加分规则 ID 列表，逗号分隔 |
| `calc_time` | DATETIME | 计算时间 |
| `is_manual` | TINYINT(1) | 是否人工调整（1 为手工赋值） |
| `adjust_reason` | VARCHAR(200) | 人工调整原因 |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`UK(event_id, round_id, registration_id)`、`IDX(meet_id, unit_id, group_id)`、`IDX(meet_id, event_id)`

### team_score 团体总分快照表
> 按单位 × 组别 × 性别口径聚合的团体总分快照，支持男团/女团/总团三张榜。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `unit_id` | BIGINT UNSIGNED | 参赛单位 `unit.id` |
| `group_id` | BIGINT UNSIGNED | 组别 `meet_group.id` |
| `score_type` | VARCHAR(32) | `MALE` / `FEMALE` / `TOTAL` |
| `rank_point_sum` | DECIMAL(10,2) | 名次分合计 |
| `bonus_point_sum` | DECIMAL(10,2) | 破纪录加分合计 |
| `relay_point_sum` | DECIMAL(10,2) | 接力项目得分合计 |
| `total_point` | DECIMAL(10,2) | 团体总分 |
| `rank_no` | SMALLINT | 团体名次 |
| `rank_display` | VARCHAR(16) | 名次显示文本（含并列） |
| `event_count` | INT | 得分项目数 |
| `athlete_count` | INT | 得分人数 |
| `calc_time` | DATETIME | 统计时间 |
| `calc_batch` | VARCHAR(64) | 计算批次号，便于整批重算覆盖 |
| `is_published` | TINYINT(1) | 是否已对外发布 |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`UK(meet_id, unit_id, group_id, score_type)`、`IDX(meet_id, group_id, rank_no)`

### medal_standing 奖牌榜快照表
> 按单位 × 组别聚合的金银铜牌快照，排序优先级由届次规则配置。

| `silver` | INT | 银牌数 |

| `sort_score` | DECIMAL(10,2) | 排序分，按配置权重折算 |
| `medal_sort` | VARCHAR(64) | 排序规则快照，如 `GOLD_SILVER_BRONZE` |
| `rank_no` | SMALLINT | 奖牌榜名次 |
| `rank_display` | VARCHAR(16) | 名次显示文本（含并列） |
| `calc_time` | DATETIME | 统计时间 |
| `calc_batch` | VARCHAR(64) | 计算批次号 |
| `is_published` | TINYINT(1) | 是否已对外发布 |
| `remark` | VARCHAR(200) | 备注 |

**索引与约束**：`UK(meet_id, unit_id, group_id)`、`IDX(meet_id, group_id, rank_no)`

### screen_config 大屏配置表
> 大屏展示方案的模块组合、刷新频率与主题，一个届次可配置多个大屏。

## 本层设计要点

1. **成绩原文与数值双列**：`result_raw VARCHAR(16)` 保留录入与显示的原始形态（`11"23`、`1:02.45`），`result_value DECIMAL(10,2)` 与 `result_unit`（`s`/`m`/`cm`/`pt`）提供可比较、可排序、可聚合的数值口径；两者同时写入避免「显示要改格式、排序要转字符串」的反复解析，也让手工计时与设备导入共用同一套排序逻辑。
2. **径赛、田赛、全能三类口径统一落表**：径赛用秒、田赛远度与高度用米（`result_unit='m'`，高度另记 `final_height`）、全能单项用 `result_score` 记分并用 `allround_group_id` 把同一运动员的多个单项归并，全能总分仍用 `result_value` + `result_unit='pt'`，因此名次与积分算法无需按项目类型分叉。
3. **风速与纪录认定有独立字段支撑**：`wind_reading` 保存风速仪读数、方向、合法上限与记录人，`result.wind_speed` 与 `is_wind_legal` 内联判定结果以支撑排序与过滤；超风速时 `is_record_candidate` 可置位但 `is_record_confirmed` 不予认定，`record_id` 与 `record_type` 明确对标的纪录条目与层级（`MEET`/`NATION` 等），认定后可直接回写纪录与加分规则。
4. **特殊状态与犯规有完整字段**：`status` 覆盖 `VALID`/`DNS`/`DNF`/`DSQ`/`NM`/`PASS`/`SCRATCH`，无效成绩的 `result_value` 置空并在排序时排在有效成绩之后；DSQ 必须填 `foul_type` 与 `foul_reason`，`result_attempt` 亦保留每次试跳的 `is_foul` 与 `foul_type`，判罚可逐次追溯。
5. **审核与留痕闭环**：`result.audit_status` 走 `DRAFT → SUBMITTED → APPROVED/REJECTED`，配套 `audit_by`/`audit_time`/`reject_reason`；每次提交、审核、驳回、修改、撤销都写 `result_audit`（`action` + `before_json`/`after_json` + `reason` + 操作人），审核通过后由 `is_locked` 锁定，需修改时先走 `REVOKE` 撤销审核，形成不可绕过的闭环。
6. **晋级名单由「规则 + 结果 + 留痕」三步生成**：以 `event_round_rule.advance_json` 的每组前 N 与递补目标为输入，按来源轮次成绩排序写入 `advance_result`，`advance_type` 区分 `GROUP_TOP`/`BEST_LOSER`/`MANUAL`，`advance_order` 给出新轮次顺序，`is_confirmed` 控制名单是否生效；人工调整后再次生成以 `UK(event_id, to_round_id, registration_id)` 幂等覆盖，不产生重复名单。
7. **积分三层结构清晰落表**：`points.rank_point` 存查 `score_rule_item` 得到的名次分、`bonus_point` 存破纪录加分、`relay_factor` 存接力倍数，三者按 `(名次分 + 加分) × 倍数` 合成 `total_point`，并保留 `score_rule_id`/`bonus_rule_ids` 记录所用规则版本，`is_manual` 与 `adjust_reason` 标记人工干预，重算时可整批覆盖而不丢依据。
8. **明细表与快照表分工明确**：`points` 是逐条结果的可追溯明细，`team_score` 与 `medal_standing` 是按 `(单位 × 组别 × 口径)` 聚合的快照，带 `calc_time`/`calc_batch`/`rank_no` 支持一键重算与批量替换；榜单查询只读快照，避免每次拉全量成绩实时聚合，同时 `is_published` 控制对外可见时机。
9. **证书与打印模板高度可配置**：`print_template` 用 `template_code` + `report_type` 区分报表，页眉页脚、Logo、签名栏、纸张规格、方向、字号与 `extra_json`（签章位置、水印）均在库内配置，`is_default` 支持届次级覆盖全局默认；`certificate` 通过 `template_id` 绑定模板，并保存 `cert_no`、`result_text`、`honor_text`、`file_id`、`qr_content` 与 `print_count`，批量生成与验真打印互不耦合。
10. **公告与大屏面向输出场景独立建模**：`announcement` 用 `scope` 区分公开/领队/裁判可见范围，`is_top`、`publish_time`、`expire_time` 控制展示时序，`screen_show` 与 `screen_duration` 决定是否进入大屏轮播；`screen_config` 用 `modules_json`、`refresh_interval`、`theme_json` 描述模块顺序、刷新频率与主题，报表现场无需改代码即可调整大屏组合。
