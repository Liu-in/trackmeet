# 前端项目目录结构（Vue 3 + TS + Vite + Pinia + Element Plus）

> 根目录：`frontend/` ｜ 包管理：pnpm ｜ 构建：Vite ｜ 组件库：Element Plus ｜ 图表：ECharts ｜ 请求：Axios
> 三种布局：`MainLayout`（管理端）、`PrintLayout`（A4 打印，无壳）、`ScreenLayout`（大屏全屏）。

## 2. 路由与权限

| 路由类型 | 路径示例 | 布局 | 权限控制 |
| --- | --- | --- | --- |
| 静态路由 | `/login`、`/403`、`/404` | 无布局 | 无需登录 |
| 动态路由 | `/schedule/plan`、`/result/entry` 等 | `MainLayout` | 登录后按 `sys_menu` 权限过滤并 `addRoute` 注入 |
| 打印路由 | `/print/order-book`、`/print/certificate` | `PrintLayout` | 需登录 + `print:*` 权限；支持 `?token=` 免登录窗口打印（可选） |
| 大屏路由 | `/screen/main` | `ScreenLayout` | 大屏 Token 或公开只读 |

**三层权限落地**
1. **菜单**：`store/permission.ts` 依据后端返回的菜单树生成路由，未授权页面不可达（手输 URL 跳 403）。
2. **按钮**：`v-perm="'schedule:auto'"` 控制显隐；组件内亦可用 `usePermission().hasPerm()` 做逻辑分支。
3. **数据**：不做前端过滤（只提示），数据范围完全由后端强制，避免「前端隐藏即安全」的误判。

## 3. 关键页面与组件对应

| 页面 | 核心组件 | 关键交互 |
| --- | --- | --- |
| `SchedulePlan.vue` | `ScheduleTimeline`、`ConflictBadge`、`ProTable` | 自动编排向导、拖拽移动（乐观更新 + 失败回滚）、锁定切换、发布、冲突定位 |
| `HeatLane.vue` | `HeatCard`、`LaneGrid`、`FieldOrderList` | 拖拽换组、道次交换、按道次顺序着色、田赛顺序拖拽、重新生成 |
| `RuleConfig.vue` | `RuleConfigPanel`、`ProForm` | 三层继承可视化（继承值灰显、覆盖值高亮）、恢复继承 |
| `ResultEntry.vue` | `ScoreInput`、`ResultBadge`、`ProTable` | 键盘流录入（Tab/Enter）、批量状态、风速、实时排名与破纪录提示、草稿保存 |
| `ResultAudit.vue` | `ProTable`、留痕抽屉 | 批量通过/驳回、撤销审核、前后值对比 |
| `AdvanceManage.vue` | `ProTable`、对比视图 | 生成晋级名单、边界并列提示、手动调整、确认 |
| `PointsBoard.vue` / `MedalBoard.vue` | `ECharts`、`ProTable` | 男子/女子/总团体切换、下钻明细、重算、导出 |
| `PrintCenter.vue` | `PrintLayout`、`ExcelImportDialog`（复用下载逻辑） | 报表类型 + 范围 + 模板 + 格式 → 预览/下载/批量 ZIP |
| `printviews/*` | `PrintLayout` | A4 分页、页眉页脚、签名栏、`window.print()` |
| `screen/*` | 独立布局 + 定时轮询 | 模块轮播、15s 刷新、断网保留最后数据 |

## 4. 工程约定

| 项 | 约定 |
| --- | --- |
| 组件命名 | 页面 `Xxx.vue`（PascalCase）；通用组件目录同名导出 |
| 状态管理 | 仅跨页面/跨组件共享状态进 Pinia；页面内状态用 `ref/reactive` |
| 接口调用 | 统一走 `api/*.ts`，禁止在组件内直接 `axios` |
| 错误处理 | `request.ts` 按 `code` 统一提示；`401` 触发刷新或跳登录；`403` 提示无权限并保留页面 |
| 类型 | 后端 VO/DTO 在 `types/` 中定义，接口函数带泛型返回 |
| 字典 | `useDict('EVENT_TYPE')` 读取并缓存，避免硬编码中文枚举 |
| 样式 | 统一 `scoped`；打印样式集中在 `styles/print.scss`；主题色变量在 `variables.scss` |
| 离线 | 不引用公网 CDN/字体；Element Plus 按需打包；图标用本地 SVG 或内置图标 |
| 性能 | 大列表虚拟滚动（分组/道次/成绩录入）；路由懒加载；ECharts 按需引入 |
