## 二、算法说明（全部为 `public final class` + `public static`，无状态、可复现）

### 2.1 名次解析与平局 —— `RankResolver.resolveRank(results, trackAscending, tieBreak)`

| 步骤 | 处理 |
| --- | --- |
| 1 | **有效性**：仅 `status=VALID` 且成绩非空者参与排名；`DNS/DNF/DSQ/NM/PASS/SCRATCH` 名次置空并排在最后 |
| 2 | **方向**：径赛 `trackAscending=true`（越小越好），田赛 `false`（越大越好） |
| 3 | **平局规则**（依 `TieBreakRule.order` 顺序比较）：`SECOND_BEST` 次优成绩（田赛多次试跳的第二好成绩）→ `BEST_ATTEMPT_ROUND` 最好成绩出现轮次（越早越优）→ `DRAW` 抽签 |
| 4 | **并列**：仍相同则 `allowParallelRank=true` 时名次并列且后续顺延（1、1、3 制，`rankDisplay` 显示「1（并列）」）；否则按报名 ID 强制区分 |

### 2.2 自动晋级 —— `AdvanceCalculator.calculate(results, rule)`

**规则：每组前 N 名直接晋级 + 其余人员按最好成绩递补至目标人数。**

1. 过滤无效成绩（可配 `excludeInvalidStatus`）与超风速成绩（可配 `excludeIllegalWind`）；
2. 按 `heatNo` 分组，各组按名次升序取前 `groupTopN` 名 → `advance_type=GROUP_TOP`；
3. 剩余人员按名次（即成绩由好到差）递补：名额 = `max(bestLoserCount, targetCount − 已晋级人数)`；→ `advance_type=BEST_LOSER`；
4. 边界并列：`tiePolicy=ALL` 把与边界成绩并列者全部录取（可超出目标人数），`TRUNCATE` 严格截断；
5. 输出 `advance_order` 从 1 连续编号（直接晋级在前、递补在后），并回填来源组次/名次/成绩。

> 名次由 `RankResolver` 写入，本身即「越好越小」，因此算法无需知道径赛/田赛方向；`heatNo` 必须由服务层填充。

### 2.3 积分计算 —— `ScoreCalculator.calculate(ranked, scoreRule, bonusRules, relayDouble)`

| 组成 | 规则 |
| --- | --- |
| **名次分** | 取 `score_rule_item` 中该名次的分值；并列时按该行 `tiePolicy`：`AVERAGE` 均分占用名次分值、`FULL` 各取本名次分值、`ORDER` 按顺序顺延取名次分值 |
| **破纪录加分** | `bonus_type=RECORD` 且层级匹配（规则 `recordType` 为空表示任意层级）：`stackable=true` 多个层级**叠加**，否则取**最高分** |
| **接力双倍** | `relayDouble=true` 且为接力项目时乘以 `bonus_type=RELAY` 的 `factor`（默认 2.00） |
| **合计** | `totalPoint = (rankPoint + bonusPoint) × relayFactor` |

### 2.4 团体总分与奖牌榜 —— `StandingCalculator`

- `teamScores(awards, unitNames)`：按 **单位 × 组别 × 口径** 汇总；口径三档 `MALE`（男子团体）/`FEMALE`（女子团体）/`TOTAL`（总团体，全部计入）；名次在「组别 × 口径」分区内计算，同分并列且后续顺延。
- `medals(finalResults, unitNames[, medalSort])`：仅决赛有效成绩的名次 1/2/3 计金/银/铜；排序默认 `GOLD_FIRST`（排序分 = 金×10000 + 银×100 + 铜），可切换 `TOTAL_FIRST`（奖牌总数优先）与 `POINT_FIRST`；同分并列。

### 2.5 风速 —— `WindValidator`

- `isLegal(windSpeed, maxLegal)`：未测风速视为合法；上限默认 **2.0 m/s**，取绝对值（顺/逆风同判）。
- `isApplicable(eventType, subType)`：`TRACK+SPRINT`、`TRACK+HURDLE`、`FIELD+JUMP` 计风速；中长跑、竞走、投掷、接力不计。
- `illegalMessage(...)`：生成中文提示文案。

### 2.6 全能查表 —— `AllroundScoreLookup`

- `lookup(table, performance, tableCode[, gender, subEventType])`：命中成绩区间 `[min, max]` 取分（区间倒序书写自动归一化）；未命中返回 0；支持按计分表编码、性别、子类型过滤。
- `total(scores)`：各单项得分求和（缺项按 0 计）。

## 五、联调步骤（curl）

```bash
BASE=http://localhost:8080/api
TOKEN=$(curl -s -X POST $BASE/auth/login -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"Admin@123"}' | sed -n 's/.*"accessToken":"\([^"]*\)".*/\1/p')
AUTH="Authorization: Bearer $TOKEN"; MEET="X-Meet-Id: 1"

# ① 成绩录入表 → 批量录入 → 风速 → 提交审核
curl -s "$BASE/results/entry-sheet?meetId=1&scheduleId=1" -H "$AUTH" -H "$MEET"
curl -s -X POST "$BASE/results/batch" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' \
  -d '{"meetId":1,"scheduleId":1,"results":[{"registrationId":1,"resultRaw":"11\"23","resultValue":11.23,"status":"VALID"}]}'
curl -s -X POST "$BASE/results/wind" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' \
  -d '{"heatId":1,"windSpeed":1.2}'
curl -s -X POST "$BASE/results/submit" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' -d '{"ids":[1,2,3]}'

# ② 审核通过（自动生成名次）→ 查看名次与留痕
curl -s -X POST "$BASE/results/approve" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' -d '{"ids":[1,2,3]}'
curl -s "$BASE/results/rank?meetId=1&eventId=1&roundId=1" -H "$AUTH" -H "$MEET"
curl -s "$BASE/results/1/audits" -H "$AUTH" -H "$MEET"

# ③ 自动晋级：每组前 2 + 递补 8 人 → 确认
curl -s -X POST "$BASE/results/advance/generate" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' \
  -d '{"meetId":1,"eventId":1,"fromRoundId":1,"toRoundId":2,"groupTopN":2,"bestLoserCount":8,"targetCount":16,"excludeIllegalWind":true}'
curl -s -X PUT "$BASE/results/advance/confirm" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' \
  -d '{"meetId":1,"eventId":1,"toRoundId":2}'

# ④ 破纪录认定 → 重算积分 → 榜单
curl -s -X POST "$BASE/results/record/confirm" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' \
  -d '{"resultId":1,"recordType":"MEET","confirmed":true}'
curl -s -X POST "$BASE/standings/recalculate" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' -d '{"meetId":1}'
curl -s "$BASE/standings/team?meetId=1&scoreType=TOTAL" -H "$AUTH" -H "$MEET"
curl -s "$BASE/standings/medals?meetId=1" -H "$AUTH" -H "$MEET"

# ⑤ 成绩册/积分表/奖牌榜/证书
curl -s "$BASE/print/results?meetId=1&eventId=1" -H "$AUTH" -H "$MEET"
curl -s -o 成绩册.xlsx "$BASE/print/results?meetId=1&format=xlsx" -H "$AUTH" -H "$MEET"
curl -s -X POST "$BASE/certificates/generate" -H "$AUTH" -H "$MEET" -H 'Content-Type: application/json' \
  -d '{"meetId":1,"certType":"RANK","eventId":1}'
```

## 八、已知边界

1. **服务端 PDF 未实现**：证书与成绩册提供 Excel 导出 + A4 网页打印（浏览器另存为 PDF），服务端 PDF 需内嵌中文字体，留待后续。
2. **计分轮次**：积分按 `score_rule.effective_round_code` 过滤生效轮次 —— 引擎提供 5 参重载 `ScoreCalculator.calculate(..., String roundCode)`，`roundCode` 非空时剔除生效轮次不符的规则行，为空则不过滤（向后兼容）。统计模块按「项目 × 轮次」分区计算并传入该分区的轮次码，因此同一项目多轮次**不会重复计分**；奖牌榜本就只取 `is_final=1`，不受影响。
3. **设备成绩导入为占位实现**：`POST /api/results/import` 已注册（`result:add`），当前直接抛业务异常提示「尚未开放」，未实现 CSV/Excel 解析与 `result_import_log` 批次留档；电子计时/测距对接建议在 P5 一并实现。
4. 全能计分表 `allround_score_table` 为全局参照表，初始化脚本仅含少量样例区间；**正式使用前需导入完整计分表**，否则查表得分为 0。
5. 破纪录加分的层级匹配规则为「规则 `recordType` 为空表示任意层级，否则需与实际纪录层级一致」；多层级叠加需将对应规则配置为 `stackable=1`。
6. 团体总分口径目前为「男子/女子/总」三档（含 `meet_group` 组别维度）；若需按「甲组/乙组」分别排名，通过 `groupId` 过滤即可。
7. 成绩与统计的重算入口为 `POST /api/standings/recalculate`，重算会**物理删除**范围内的 `points`/`team_score`/`medal_standing` 后重建，请避免与人工调整并行操作。
8. 「名次生成」使用 `result:approve` 权限（初始化数据未定义 `result:rank` 编码），「名次预览」使用 `result:list`；前端按钮绑定请以此为准。
