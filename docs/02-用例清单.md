## 2. 关键用例详细描述

### UC-REG-04 报名限制与冲突校验
- **参与者**：TEAM_LEADER（触发）、系统（执行）
- **前置**：报名处于开放期；项目与规则已配置。
- **主流程**：
  1. 领队提交报名（单位 + 运动员 + 项目）。
  2. 系统比对规则引擎：每人限报项数、每单位每项限报人数、组别/性别匹配、年龄/年级约束、接力人数上下限。
  3. 系统检查重复报名（同一运动员同一项目同一轮次）。
  4. 全部通过 → 写入 `registration`，状态 `PENDING`，返回成功。
- **备选/异常流**：
  - 2a. 超项/超人数 → 返回具体违规项与当前计数，报名不写入。
  - 3a. 重复报名 → 返回已存在记录 ID，提示合并或修改。
  - 5a. 报名期已截止 → 返回 `MEET_REG_CLOSED`，仅 MEET_ADMIN 可代报名。
- **后置**：`registration.limit_check_result` 记录校验快照，供审核参考。

### UC-REG-05 审核报名
- **参与者**：MEET_ADMIN / REGISTRAR
- **前置**：存在 `PENDING` 报名。
- **主流程**：筛选/搜索待审列表 → 勾选（或全选）→ 审核通过 → 状态置 `APPROVED`，记录审核人与时间 → 报名数据进入编排可用池。
- **备选流**：退回 → 必填退回原因 → 状态 `REJECTED`，领队端可见原因并可修改后重新提交。
- **业务规则**：已进入编排的报名不允许退回，只能通过「编排前撤销」流程。

### UC-SCH-02 自动编排日程
- **参与者**：SCHEDULER
- **前置**：报名已截止并通过审核；项目规则、场地、单元、项目预计时长齐备。
- **主流程**：
  1. 选择编排范围（全部 / 指定组别 / 指定项目 / 指定单元）。
  2. 系统汇总各项目轮次的参赛人数与预计时长（含田赛试跳时间、检录提前量）。
  3. 按项目类型排序（径赛优先、田赛并行占用场地），在可用单元与场地时间轴上装箱（首次适应 + 冲突回退）。
  4. 生成 `schedule` 草案（状态 `DRAFT`），同时触发分组分道（UC-SCH-03/04/05）。
  5. 运行冲突检测（UC-SCH-06），输出冲突清单与日程预览。
- **备选/异常流**：
  - 3a. 时间不足 → 提示缺口（所需单元数 vs 可用单元数），给出建议（延长单元、增加场地、压缩项目时长）。
  - 3b. 存在锁定条目 → 锁定条目作为固定块参与装箱，不可移动。
- **后置**：日程草案可拖拽调整；未发布前对领队/观众不可见。

### UC-SCH-08 调整分组与道次
- **参与者**：SCHEDULER
- **前置**：已生成分组。
- **主流程**：
  1. 打开某项目轮次的分组分道视图。
  2. 拖拽运动员在组间移动，或直接修改其道次。
  3. 系统实时校验：同组重复、单位冲突提示（可强制）、道次占用冲突。
  4. 保存 → 写入 `heat_member` / `lane`，记录变更日志。
  5. 若该组已锁定 → 拒绝直接修改，提示先解锁。
- **后置**：秩序册与检录表数据同步刷新。

### UC-RES-02 录入田赛成绩（含试跳试掷）
- **参与者**：REFEREE
- **前置**：该项目某轮次正在比赛；出场顺序已生成。
- **主流程**：
  1. 选择项目轮次 → 显示出场顺序表。
  2. 逐人录入每轮次试跳/试掷成绩（可录 X 表示失败、`-` 表示免跳）。
  3. 系统即时标记最好成绩、当前排名、破纪录候选。
  4. 全部录入完成 → 提交审核（状态 `SUBMITTED`）。
- **备选流**：
  - 2a. 录入高度项 → 按升杆方案自动生成待录高度行。
  - 4a. 达标后免跳 → 后续高度自动标记 `PASS`。
- **业务规则**：成绩取最好一次；平局按次优成绩 → 最远成功轮次 → 并列（规则可配）。

### UC-RES-08 自动晋级生成下一轮名单
- **参与者**：SCHEDULER / CHIEF_REFEREE
- **前置**：本轮成绩已审核通过；下一轮已配置晋级规则。
- **主流程**：
  1. 选择项目与轮次 → 点击「生成晋级名单」。
  2. 系统按规则执行：各组前 N 名直接晋级 → 剩余人员按最好成绩排序 → 递补至目标人数。
  3. 剔除 DNS/DNF/DSQ/NM 及超风速非法成绩（规则可配）。
  4. 生成下一轮参赛名单并写入 `advance_result`，同步生成下一轮分组分道草案。
- **备选流**：
  - 3a. 递补边界成绩并列 → 按规则全部录取或提示人工裁决。
  - 5a. 已存在下一轮手动调整 → 提示重生成将覆盖，需确认。
- **后置**：晋级名单可公告、可打印。

### UC-STA-02 计算积分
- **参与者**：系统（由成绩审核通过触发）/ MEET_ADMIN（手动重算）
- **前置**：名次已生成；名次分表、破纪录规则、接力双倍规则已配置。
- **主流程**：
  1. 取项目轮次的有效名次记录。
  2. 按 `score_rule` 取各名次分值；并列名次按 `tie_policy`（均分法/满额法）计算。
  3. 判定破纪录 → 按 `bonus_rule` 加分（区分层级，支持叠加开关）。
  4. 接力项目 → 乘以双倍系数。
  5. 写入 `points` 明细（含分项来源标记），汇总刷新 `team_score` 快照与奖牌榜。
- **异常流**：
  - 4a. 名次分表缺失该名次 → 记 0 分并写警告日志。
- **后置**：积分榜、奖牌榜、证书数据可用。

### UC-PRT-01 打开打印中心并预览
- **参与者**：SCHEDULER / MEET_ADMIN / ANNOUNCER
- **前置**：对应数据已就绪（如秩序册需编排完成）。
- **主流程**：
  1. 进入打印中心，选择报表类型（秩序册/检录表/分道表/成绩公告/成绩册/积分表/奖牌榜/证书）。
  2. 选择范围（届次、单元、组别、项目、单位、日期）。
  3. 选择输出格式（网页预览 / PDF / Excel / Word / CSV）与打印模板。
  4. 系统渲染 → 页面 A4 预览（可翻页）→ 下载或直接打印。
- **后置**：记录打印任务（可选留痕）。

### UC-BIG-01 展示大屏
- **参与者**：VIEWER（无需登录也可只读展示，可通过大屏 token 访问）
- **前置**：成绩/公告数据存在；大屏模块已配置。
- **主流程**：
  1. 打开大屏地址（全屏、无导航）。
  2. 大屏轮播：实时成绩 → 晋级名单 → 奖牌榜 → 团体总分 → 公告/倒计时。
  3. 按配置间隔（默认 15s）自动刷新数据。
- **异常流**：网络中断 → 保留最后数据 + 顶部提示「数据更新时间」。
