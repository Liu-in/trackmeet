## 二、PDF 方案（中文字体内嵌）

中文 PDF **必须内嵌字体**——PDF 内置的 `STSong-Light` 等 CJK 字体在多数阅读器中不可用，因此本项目采用
**OpenPDF（LGPL/MPL，`com.lowagie.text`）+ TrueType 中文字体内嵌**（`IDENTITY_H + EMBEDDED`）。

### 2.1 字体自动发现顺序（`PdfFontProvider`）

1. 配置项 `trackmeet.pdf.font-path`（`.ttf`，或 `.ttc` 写作 `xxx.ttc,0`）；
2. Windows：`simhei.ttf` → `simkai.ttf` → `simfang.ttf` → `Deng.ttf` → `msyh.ttc,0` → `simsun.ttc,0`；
3. Linux：`/usr/share/fonts/truetype/droid/DroidSansFallbackFull.ttf` → 文泉驿（microhei/zenhei）→ Noto CJK → AR PL uming；
4. macOS：`PingFang.ttc,0`；
5. classpath 资源 `fonts/NotoSansSC-Regular.ttf` 等（可选自备）。

**Docker 开箱可用**：后端镜像运行时阶段已安装 `fonts-droid-fallback`（Apache-2.0，含完整 CJK 覆盖），
路径 `/usr/share/fonts/truetype/droid/DroidSansFallbackFull.ttf`，无需额外配置。
**Windows 开发机**：通常命中 `C:/Windows/Fonts/simhei.ttf`，同样无需配置。

### 2.2 能力探测与降级

`GET /api/print/pdf/capability` 返回 `PdfCapability{available, fontPath, fontName, embeddedMode, message, candidates}`：

- `available=true`：前端启用「下载 PDF」按钮，并展示已加载字体名；
- `available=false`：`message` 给出配置指引（含候选路径列表），前端禁用 PDF 按钮并提示
  「可改用浏览器 A4 打印另存为 PDF」——**A4 打印通道始终可用，PDF 不是唯一出口**。

渲染时若字体缺失，服务端抛 `BizException(PDF_FONT_MISSING)`（错误码 50003），不会产出空白或乱码文件。

### 2.3 渲染能力（`PdfTableRenderer`）

| 能力 | 说明 |
| --- | --- |
| 纸张 | A4 / A3，纵向 / 横向（**任一节声明横向时整份文档按横向输出**） |
| 页眉 | 主标题（加粗放大）、副标题、信息行（灰色小字） |
| 表格 | 多节渲染；表头浅底加粗、行间浅色分隔线、**长表跨页自动重复表头** |
| 列宽 | 按各列最长内容自适应（CJK 按双宽计），可用模板 `extra_json.columnWidths` 覆盖 |
| 页脚 | 页脚说明 + 打印时间 + 页码（`第 X 页`） |
| 签名区 | 左/中/右三栏（默认「记录员 / 裁判长 / 技术代表」） |
| 空数据 | 仍输出含标题与「暂无数据」的合法 PDF，不报错 |

| 积分表 | `GET /api/print/pdf/points`（`print:standings`） | `/excel/points` | `StandingPrintSupport` |

- 每次 PDF/Excel 生成都会写入 `sys_print_log`（报表类型、参数 JSON、格式、模板、操作人、IP、状态、打印时间）。

## 四、打印模板配置（`print_template`）

| 字段 | 作用 |
| --- | --- |
| `template_code` / `template_name` | 届次内唯一编码与名称（唯一键 `uk_meet_template_code`） |
| `report_type` | `PROGRAM` 秩序册 / `START_LIST` 检录分道表 / `RESULT` 成绩公告 / `POINTS` 积分表 / `MEDAL` 奖牌榜 / `CERT` 证书 |
| `header_html` / `footer_html` / `signature_html` | 页眉 / 页脚 / 签名区（**去标签后作纯文本输出**，不做 HTML 渲染） |
| `page_size` / `orientation` / `font_size` | 纸张规格、方向、基准字号 |
| `show_page_no` / `show_print_time` | 页码与打印时间开关 |
| `is_default` | 同一 `report_type` 仅允许一个默认模板（保存时自动把旧的置 0） |
| `extra_json` | 扩展：`columnWidths`（按节指定列宽）、水印、盖章位置等 |

**生效顺序**：显式 `templateId` → 该 `report_type` 的默认模板 → 内置默认（A4 纵向、字号 9、显示页码与打印时间、三栏签名）。
接口：`GET/POST/PUT/DELETE /api/print/templates`、`GET /api/print/templates/default?reportType=`（权限 `print:template:list/add/edit`，删除用 `edit` 并改写唯一键后逻辑删除）。

## 五、公告与大屏

| 接口 | 权限 | 说明 |
| --- | --- | --- |
| `GET/POST/PUT /api/announcements[/{id}]` | `notice:list` / `notice:add` / `notice:edit` | 公告分页、新增、修改 |
| `DELETE /api/announcements/{id}` | `notice:delete` | 删除（已发布需先下线） |
| `PUT /api/announcements/{id}/publish` | `notice:publish` | 发布 / 下线 / 转草稿，可同时设置大屏推送与停留秒数 |
| `GET /api/screen/config`、`POST`、`PUT /{id}` | `screen:config:list` / `add` / `edit` | 大屏配置（轮播与刷新间隔、显示模块、主题） |
| `PUT /api/screen/config/token` | `screen:token` | 重新生成大屏访问令牌（旧令牌立即失效） |
| `GET /api/screen/board` | `screen:board` | 大屏聚合数据（登录态） |
| `GET /api/screen/public/board?meetId=&token=` | **匿名**（`/api/screen/public/**` 放行，接口内校验令牌） | 会议室大屏直接打开，无需登录 |

**匿名大屏页面路由**：`/screen/public-board?meetId=1&token=xxx`（`router/index.ts` 中的静态公开路由，`meta.public=true`，不套主框架、无需登录态）；
应用内查看走权限菜单登记的 `/screen/board`（需 `screen:board` 权限，套主框架）。大屏配置页生成的「匿名大屏地址」即为前者。

> **令牌存储说明**：`screen_config` 表 DDL 中**没有** `access_token` 列（`sql/04` 与字段清单均无），
> 为守住「实体列与 DDL 逐字一致」的约束，令牌持久化在既有 `theme_json` 的保留键 `accessToken` 上
> （对外字段名仍为 `accessToken`，接口无感知）。若后续希望改为独立列，只需
> `ALTER TABLE screen_config ADD COLUMN access_token VARCHAR(32) NULL;` + 实体加 `@TableField("access_token")` +
> 替换 `ScreenServiceImpl` 的 `extractToken/writeToken` 两处实现（各约 5 行）。

> **正文安全**：`announcement.content_html` 在**写入与输出两侧**均经 [`HtmlSanitizer`](../backend/src/main/java/com/trackmeet/common/util/HtmlSanitizer.java) 白名单净化
> （删除 `script/style/iframe/svg/math/form/...` 元素、`on*` 事件属性与 `javascript:/data:` 协议，只保留 `p/br/strong/em/ul/li/a/table...` 等安全标签），
> 前端 `v-html` 前的去 `<script>` 作为第二道防线。

`ScreenBoardVO` = 届次信息 + 已发布且勾选推大屏的公告 + 奖牌榜前 20 + 团体总分（TOTAL）前 20 + 最近 20 条已审核成绩 + 配置 + 刷新时间；
单次请求 **不超过 5 条查询**（全部为自己的 `@Select` 投影，自带 `meet_id`/`deleted` 条件）。

## 九、已知边界

1. **PDF 依赖中文字体文件**：Docker 镜像与常见 Windows 环境已内置/自带，可直接使用；极简镜像需挂载字体或配置 `trackmeet.pdf.font-path`，否则 PDF 端点返回 50003，此时请使用 A4 网页打印另存为 PDF。
2. **模板中的 HTML 不渲染**：`header_html`/`footer_html`/`signature_html` 仅去标签后作为纯文本输出，避免服务端 XSS 与渲染复杂度。
3. **公告正文已做服务端净化**：`content_html` 在写入（新增/修改）与输出（详情/列表/大屏取数）两侧均经 `HtmlSanitizer` 白名单净化，
   仅保留安全标签与 `a[href|title]`；前端 `v-html` 前的去 `<script>` 为第二道防线。若需更严格的富文本能力（图片、表格样式），
   建议改用受控富文本编辑器并同步扩展白名单。
4. 大屏匿名访问依赖 `screen_config.access_token`（32 位），入口为静态公开路由 `/screen/public-board?meetId=&token=`；请勿将地址公开到互联网，令牌可随时重置。登录态大屏入口 `/screen/board` 需 `screen:board` 权限。
5. 证书目前输出 **Excel + PDF（服务端）与 A4 网页打印**三种通道；证书版式若需盖章图片、二维码图形，可在模板 `extra_json` 扩展后由 P6 迭代。
6. 本机无 JDK，PDF 渲染与 9 个单元测试**已实现但未实际执行**；请在具备 JDK 的环境运行并抽查一份中文 PDF。
